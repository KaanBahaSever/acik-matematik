# 🌿 Açık Matematik

Lisans matematik derslerinden derlenmiş, açık kaynaklı ve reklamsız Türkçe not arşivi.

🌐 **[acik-matematik.com](https://acik-matematik.com)**

## 🤝 Katkıda Bulunma

Eksik bir ispat, hatalı bir işlem ya da eklenmesini istediğiniz bir konu mu var? Bu arşiv hepimizin.

1. Depoyu fork'layın ve bir dal açın.
2. Değişikliğinizi yapın; notlar Türkçe, kod İngilizce yazılır.
3. Yerelde derleyip bakın: `python scripts/build.py <ders-adi>`
4. Pull request açın.
